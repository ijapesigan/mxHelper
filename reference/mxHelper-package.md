# mxHelper: Helper Functions for 'OpenMx'

Helper functions for 'OpenMx' models: matrices with labels, bounds, and
vectors of free parameters; covariance matrices from the LDL
decomposition with a softplus diagonal; starting values for vector
autoregressive models; and fitting until the Hessian is positive
definite, with diagnostics and bound handling. Each exported function
has an internal version without input checks that other projects can
copy.
